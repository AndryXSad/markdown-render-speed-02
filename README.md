A dependency-free, from-scratch Markdown parser that renders byte-identical HTML to marked 18.1.3 with its default options (CommonMark 0.31.2 + GFM 0.29), built for speed. `parse.js` exports `parse(markdown)`; `main.ts` reads `/input/cases.json` and writes `/output/html.json`.

## Run it

```sh
node main.ts
```
